# Logbook

One file per work session, named `YYYY-MM-DD.md` (append `-b`, `-c` for a
second session the same day). Each entry records what was done, what failed
and what was decided, with links to commits, ADRs and run IDs. The logbook is
the source for the integration report (E3.4), the paper's methods section and
the talk.

Template:

```markdown
# YYYY-MM-DD — short title

**Platform:** grid5000 | home | none · **Hours:** n

## Done
## Failed / surprises
## Decisions
## Next
```
